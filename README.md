# Perishables Management System

A customisable desktop application for managing perishable inventory
in retail stores.

## Planned Features

- Product and batch management
- Expiry monitoring and alerts
- FEFO-based stock prioritisation
- Stock movement and wastage tracking
- Inventory dashboard and reports
- Customisable themes and dashboard widgets

## Planned Technology Stack

- Python
- PySide6
- SQLite
- SQLAlchemy
- pytest

## Project Structure

- `src/ui/` — Desktop interface
- `src/models/` — Data models
- `src/services/` — Inventory and expiry business logic
- `src/database/` — Database configuration
- `tests/` — Automated tests
- `docs/` — Software engineering documentation
- `assets/` — UI assets
